# GradLink AI

Build GradLink AI, a modern, responsive South African AI-powered career and opportunity platform for university/TVET students, graduates, and unemployed young people. Create a polished, cohesive demo covering the homepage, AI Career Coach, student dashboard with profile/CV/saved opportunities/application Kanban, searchable Opportunity Hub with filters and AI match explanations, application assistant, interview coach, Career Launch Academy progress, alerts, employer portal, dedicated WIL Connect, trust/safety, mission/vision/impact, and responsible AI disclaimer. Use realistic South African demo opportunities and a deep blue, purple, white, light-grey youthful professional visual system. Make the core flows interactive with strong empty/demo states, accessibility, responsive navigation, and no claim of real employment guarantees.
